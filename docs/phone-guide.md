# 📱 Using Road to LA on your phone

**App link:** https://aerwinapollo01.github.io/la-marathon/

Road to LA is a web app you install from the browser. Once installed, it opens full-screen from your home screen like a normal app and works offline.

---

## 1. Install it (one time, about 1 minute)

### iPhone
1. Open the link in **Safari**. It has to be Safari; Chrome on iPhone can't install web apps.
2. Tap the **Share** button (the square with an arrow pointing up).
3. Scroll down and tap **Add to Home Screen**, then **Add**.
4. Open **Road to LA** from the sunset "26.2" icon on your home screen.

### Android
1. Open the link in **Chrome**.
2. Tap the **⋮** menu → **Install app** (or **Add to Home screen**).
3. Open it from your home screen.

> ⚠️ **Always open it from the home-screen icon, not a browser tab.** On iPhone, the installed app and Safari store data separately, so runs logged in a Safari tab won't appear in the app.

---

## 2. First-time setup (2 minutes)

Your runs from **Oct 11, Oct 13 and Oct 15** are already loaded.

1. **Stats → Shoes:** enter your shoe model and the date you started wearing them. This drives the mileage tracker (buy the next pair at 250 mi, retire at 350).
2. **Stats → Settings & data → Export backup:** save a first backup to Files / iCloud Drive (see §6).

That's it. Goal tiers (A 4:00 · B 4:30 · C sub-5) are already set.

## 3. Your daily routine

| When | Where | What |
|---|---|---|
| **Morning, first steps** | Today → **Morning check** | Slide **Achilles** and **Arch/heel** pain (0–10), tap **Log check-in**. Follow the advice it shows. |
| **After a run** | **＋** button | Log the run (details below). |
| **After the gym** | Today → **💪 Log strength** | One tap. Aim for 2 a week. |
| **Sick or sore?** | Today → **🛡️ Shield day** | Excuses today's miles; your streak pauses instead of breaking. |

### What the morning check means
| Worst score | Advice |
|---|---|
| 0–3 ✅ | Run as planned. |
| 4–5 ⚠️ | Easy only. Swap any workout for an easy run or the bike. |
| 6+ 🛑 | No running today. Take a shield day; bike only if it's pain-free. |

## 4. Logging

Tap the orange **＋** button (bottom right). The form opens with **today's plan already filled in**.

### A run
1. Pick the type (Easy, Long, Tempo, Fartlek, Marathon pace, Recovery, Time Trial, Race).
2. Check the **date** and **miles** (copy the miles from your watch).
3. Enter the **time** in the h : min : sec boxes. Pace calculates live.
4. Set **effort** (1–10), add a note if you want, tap **Save**.

### A bike / cross-training session
1. Pick **🚴 Cross-train**. The form switches to **Minutes** and **Avg HR**.
2. Enter minutes and your average heart rate. It tells you if you're in range:
   - **Rest-day recovery ride:** 100–115 bpm
   - **Saturday steady ride:** 120–135 bpm (light resistance, 80–95 rpm)
3. Cross-training **never counts as running miles.** It earns its own XP.

### Fix or delete an entry
**Runs** tab → tap the entry → edit and **Save changes**, or **Delete**.

## 5. The tabs

| Tab | What's there |
|---|---|
| 🏠 **Today** | Countdown, level & XP, morning check, today's workout + target pace, this week's 7-day strip, tomorrow's preview. From Week 10, your next race-prep item. |
| 🗺️ **Journey** | All 21 weeks as a map. Tap any week to see its days. 🎯 = test weeks, ⛰️ = 20-miler, 🏁 = race. **🏁 Race-day checklist** button at the top. |
| 📝 **Runs** | Every run and bike session, newest first. |
| 📊 **Stats** | Predicted marathon + goal tier · **checkpoint times** · body-check grid (14 days) · shoe mileage · weekly miles chart · pace zones · settings & backup. |
| 🏆 **Trophies** | Badges and the level ladder (Dodger Stadium → Century City). |

### Entering test results (Stats → Checkpoints)
After each test, type your time:
- **5K (Nov 7):** `m:ss`, e.g. `27:45`
- **10K (Dec 5):** `m:ss`, e.g. `57:30`
- **Half (Jan 17):** `h:mm:ss`, e.g. `2:05:10`

Your predicted marathon, goal tier and **every training pace** update instantly.

## 6. Backups ⚠️ important

Your data lives **only on your phone**. Nothing is uploaded, and the GitHub repo never sees your runs.

- **Export a backup every week or two:** Stats → **⬇️ Export backup** → save to Files / iCloud Drive.
- **iPhone may clear a web app's data** if you don't open it for several weeks, or if you clear Safari's website data. A backup protects you.
- **New phone or lost data?** Install the app, then Stats → **⬆️ Import backup** and pick the file.

## 7. How the game works

| You do | You earn |
|---|---|
| Each mile run | +10 XP |
| Hit a planned run (≥90% of planned miles) | +25 XP |
| Long run / workout bonus | +50 / +40 XP |
| ⭐⭐⭐ week | +100 XP |
| Test result entered | +100 XP |
| Strength session | +20 XP |
| Cross-training day | +15 XP |
| Morning check-in | +5 XP |
| Race-checklist item | +10 XP |

- **Week stars:** ⭐ 70% of planned miles · ⭐⭐ 90% · ⭐⭐⭐ 90% + long run + workout done.
- **🔥 Streak:** weeks in a row at ≥80% of planned miles. Rest days never break it; shield days pause it.
- **Levels** follow the course: Dodger Stadium → Chinatown → Little Tokyo → Echo Park → Silver Lake → Los Feliz → Hollywood → Sunset Strip → Beverly Hills → Century City.

## 8. Updates & troubleshooting

| Problem | Fix |
|---|---|
| **App didn't pick up a change** | Fully close it (swipe it away) and reopen with a connection. Updates load on the next open. |
| **Using it offline** | Works fine. Log as usual; everything is stored on the phone. |
| **Runs missing** | Make sure you opened it from the **home-screen icon**, not Safari. If they're really gone, use **Import backup**. |
| **Wrong miles on a day** | Runs tab → tap the entry → fix → Save changes. |
| **Want to start fresh** | Delete the home-screen app *and* clear Safari website data for `aerwinapollo01.github.io`, then reinstall. (Export first!) |
